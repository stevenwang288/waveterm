# 当前任务进展

## 当前任务
在终端块头部的路径标题右键菜单中增加“在文件管理器中打开/显示当前路径”能力。

## 当前状态
- 已完成前置架构梳理，确认这是 `Electron + React/TypeScript + Go` 的桌面应用，分屏不是“纯终端 UI”。
- 新需求已定位到终端块头部的路径标题区域，不是 Electron 原生窗口标题栏。
- 右键菜单实现入口在 `frontend/app/block/connectionbutton.tsx` 与 `frontend/app/block/connectionbutton-menu.ts`。
- 现有 Electron IPC 已具备 `openNativePath(filePath)`，可直接复用，不需要新增主进程接口。
- 已完成前端实现：菜单新增“文件管理器打开/显示路径”项，并接到 renderer 侧 `getApi().openNativePath(...)`。
- 目标测试 `npm test -- frontend/app/block/tests/connectionbutton.test.ts` 已通过，当前为 `7 passed`。
- 已记录验证结果到本地 self-improver 状态，并已通过 `final-gate.ps1 -RequireVerification`。

## 本次实现约束
- 只给终端路径标题的右键菜单加项，不改普通连接按钮菜单。
- 只在本地终端路径可用时启用打开能力；远端路径或空路径保持禁用。
- 打开路径一律使用 `terminalCwd`，不拿仅用于展示的 label 去兜底打开。
- 菜单文案复用 `native.revealInManager` 与平台管理器名称。
